# Instructions for coding agents (Codex, Claude Code, others)

- Work on branch `dev`; make `feature/<task-id>-<name>` branches from it. Never push to `main`.
- **Frontend work: read `frontend/README.md` and `docs/design/civisar-prototype.html` first.** The prototype is the UI source of truth.
- Safety rules: never label anything "safe"; use evidence labels Observed / Reported / Corroborated / Unknown; no live vehicle or phone tracking; login required.
- Contracts live only in `docs/contracts/`. No large data or secrets in Git.
- Commits use the human author's name, no AI co-author line.
